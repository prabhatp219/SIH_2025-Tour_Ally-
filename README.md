Tour Ally

A smart travel companion platform built to simplify trip planning, navigation, and tourist assistance. Tour Ally helps users explore destinations efficiently with interactive features, modern UI, and real-time assistance.

🚀 Features
🌍 Explore tourist destinations
🤖 Integrated chatbot assistant
📱 Responsive and modern UI
⚡ Fast performance using Vite
🎨 Clean frontend built with React
